# Aarush Singh — Developer Portfolio

Personal developer portfolio and digital platform engineered for **Aarush Singh**, B.Tech student in **Artificial Intelligence & Data Science** at **CGC University**.

Built with an editorial aesthetic, dark slate background (`#2C2C2C`), muted burgundy accents (`#802938`), real-time GitHub integration, and transactional contact dispatch via Brevo.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (Turbopack) & React 19
- **Styling**: Tailwind CSS v4, Lucide Icons, Framer Motion
- **Visuals**: HTML5 Canvas mathematical sine wave field
- **Email Backend**: Brevo REST API / SMTP Relay & Nodemailer
- **PDF Engine**: PDFKit & Standalone Print CSS

## 📦 Getting Started

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/aarush0008x/aarush0008x.git
cd aarush-portfolio
npm install
```

### 2. Configure Environment Variables
Create a `.env.local` file:
```env
BREVO_SENDER_EMAIL=nimocodeai@gmail.com
BREVO_API_KEY=your_brevo_api_key
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view your portfolio.
